What this skill does

It handles every step of putting a Facebook/Instagram ad live via Meta's Marketing API:

  • Uploads your images or videos to your ad account.
  • Picks the right structure — Meta's Flexible Ad Format, where one ad contains multiple images/videos × multiple texts × multiple headlines, and Meta's algorithm picks the best combinations.
  • Drafts ad copy from your landing page if you don't have any yet — or accepts copy you've written.
  • Creates a new ad set if you need one (with sensible Cost Cap or ROAS defaults), or publishes into an existing one.
  • Generates a Python publish script for the batch, runs it, and saves it on disk so you can re-run or audit it later.
  • Activates and verifies all three levels (campaign + ad set + ad) — Meta's activation doesn't cascade, so this matters.

The guided flow

You type /meta-ad-publish in Claude Code. It asks you these, in order:

  1. First-run config (asked once, then saved) "What's your ad account ID? Page ID? Pixel? Instagram?"
  2. Image ad or video ad? One type per ad — match what works in production.
  3. Where are your assets? Folder of PNGs/JPGs, or path to MP4 files.
  4. Existing ad set, or create a new one? If new: Cost Cap, ROAS, or both? What cap (suggests AOV÷2.2)? What ROAS floor?
  5. Landing page URL + CTA? "Learn More", "Shop Now", "Sign Up", "Get Offer"
  6. Image clusters (only if you have >10 images — Meta caps at 10/ad) Skill proposes 1 or 2 thematic clusters; you approve, swap, or split differently.
  7. Have copy ready, or want me to draft? "I'll paste my own", "Draft 5 angles per cluster from my LP", or mix.
  8. Review the generated Python script + run it All ads created PAUSED — nothing live yet.
  9. Activate? Skill activates campaign + ad set + ads, then verifies effective_status on all three.

Install — one time

1. Download the skill

One zip file. No accounts, no GitHub. Just download and unzip:

↓ Download meta-ad-publish.zip (26 KB)

Unzip it somewhere you'll remember — Desktop, Documents, anywhere.

2. Open the unzipped folder in Claude Code

Open Claude Code, then either drag the unzipped meta-ad-publish folder into the Claude Code window, or open it from Claude Code's File → Open Folder menu.

3. Add your Meta token

You already generated this in Step 1 — the Meta API setup guide. In the unzipped folder, create a file called .env (with the leading dot) and put your token in it:

META_ACCESS_TOKEN=EAC...your-long-token...

There's a .env.example in the folder you can copy from. The skill will help with this on first run if you'd rather just paste the token when asked.

4. Run it

In Claude Code, type:

/meta-ad-publish

The first run asks for your ad account ID, page ID, Instagram User ID (optional), and Pixel ID. It saves them — you won't be asked again.

Why a generated script, not direct API calls?

The skill writes a Python script for each batch, then runs it

Reasons:

  • Re-runnable. If something fails halfway, fix the script and re-run — without re-answering all the questions.
  • Auditable. The exact payload sent to Meta is on disk. If Meta rejects something, the script is what you debug.
  • Survives interrupts. A crashed Claude Code session doesn't lose your batch.
  • Matches what works. Every successful publish across thousands of ads followed this pattern.

Each run lands at ./publish-runs/publish-<date>-<batch>.py — yours to keep.

Locked rules the skill follows

You don't need to remember any of these — the skill enforces them. Listed here so you know the guardrails:

  • Every ad created PAUSED. Activation is a deliberate, verified step.
  • Uses Flexible Ad Format, not Dynamic Creative (which only allows 1 ad per ad set).
  • Activation does not cascade — campaign, ad set, and ad each verified separately via effective_status.
  • ROAS ad sets reuse the Cost Cap creative ID (preserves Meta's learning).
  • Hard limits per ad: 10 images / 10 videos, 5 primary texts, 5 headlines.
  • API version v25.0 throughout.

If you're curious why each rule exists: 13 documented Meta API failure modes are captured in the skill's failures-and-fixes reference. Every one of them has burned someone before.

Welcome

Meta Marketing API — Access Token Setup

Hi Nadja — this walks you through getting a Meta access token so you can load up ads through Claude Code without having to go through the Meta UI every time.

Once you have the token, you'll paste it into your Claude Code session and it'll handle the rest.

Click through one step at a time. Click any screenshot to zoom in.

1
Stage 1 · System User

Create the System User

Go to business.facebook.com → Settings → Users → System users. Click Add in the top right.

Name it something you'll recognise — for example API Ads Loader. Set the role to Employee access.

i What's a System User?

It's a non-human user that exists only to issue API tokens.

2
Stage 2 · Create App

Open Meta for Developers and create a new App

Click Create new app ID.

i Why a separate "App"?

Meta's API access is granted at the App level, not at the business level. The app is the container for the API permissions — and the token we'll generate at the end is bound to that app + the system user from Step 1.

3
Stage 2 · Create App

Name the App

Give the app a name — API Ads Loader is fine. Add your contact email. Click Next.

4
Stage 2 · Create App

Pick the use case: "Create and manage ads with Marketing API"

On the use cases screen, click "Create and manage ads with Marketing API". This is the one that unlocks ad account access.

5
Stage 2 · Create App

Connect the app to your Business

Pick your Business from the dropdown — the one that owns your Mat & Vic's ad account. Click Next.

! Important

You must attach the app to your Business at this step. If you skip it, the system user from Step 1 won't be able to install the app later, and the token won't have access to ad accounts.

6
Stage 2 · Create App

Confirm requirements and create the App

Meta will show a "Requirements" page. For Marketing API there are usually no requirements identified — just click Next.

Then on the Overview screen, click Create app.

7
Stage 3 · Connect App to System User

Switch back to Business Suite and open Apps

Now switch back to business.facebook.com. In the left sidebar under Accounts, click Apps.

You should see the app you just created in the list.

8
Stage 3 · Connect App to System User

Click "Assign Access" on the app

Click into the app, then click the Assign Access button.

9
Stage 3 · Connect App to System User

Pick the System User and toggle 4 permissions on

In the assignment dialog, select the System User you created in Step 1. Then toggle these 4 app permissions on:

  • ✓ Develop app
  • ✓ View insights
  • ✓ Test app
  • ✓ Manage app

Click Save changes.

10
Stage 3 · Connect App to System User

Verify the app is installed on the System User

Go back to Users → System users. Click your system user, then click the Installed apps tab. You should see the app listed there with Full control.

✓ Checkpoint

If you see your app under Installed apps, the wiring is correct. Move on.

11
Stage 4 · Ad Account Access

Give the System User access to the Mat & Vic's ad account

Still in Business Suite. In the left sidebar under Accounts, click Ad accounts, then click into the Mat & Vic's ad account.

Click Assign access, then add the System User you created.

12
Stage 4 · Ad Account Access

Toggle "Manage campaigns (ads)" ON

In the permissions panel, under Partial access, turn Manage campaigns (ads) on. Leave the others off — that's all the token needs.

Click Save changes.

13
Stage 5 · Generate Token

Generate the access token

Back to Users → System users. Click your system user. In the top right, click Generate token.

Pick the app you created (the one we wired up in Stages 2 and 3).

Set expiration to 60 days (Meta's recommended option).

Pick these 4 permissions in the permission picker:

  • ✓ ads_management
  • ✓ ads_read
  • ✓ pages_manage_ads
  • ✓ pages_read_engagement
14
Stage 5 · Generate Token

What happens after you click Generate

Click Generate token. One of two things will happen — and which one depends on how your business is set up:

→ Path A — Token appears immediately (most likely your case)

The screen will show you a long string starting with E… (usually EAC or EAA). This is the token. Copy it right away — Meta will only show it once.

Save the token somewhere safe and paste it into your Claude Code session when it asks for the Meta access token. That's what unlocks Claude Code to load ads for you without going through the UI.

There's no screenshot for this path because Andrew's own business hit Path B — but for most setups (including yours) the token generates on the spot.

⚠ Path B — "Someone else needs to approve" warning

If your business has admin gating turned on, you'll see a yellow banner that reads:

"Someone else needs to approve request to generate an access token."

If this happens, Meta has already sent the request to another admin in your business. Wait for them to approve, then come back to this same screen — the token will appear. Save it and paste it into your Claude Code session when prompted.

i Other things you might also need to check

Earlier in your sidebar you may have seen System users showing the assigned assets and app warnings (screenshot below). That's normal — once Stages 3 and 4 are saved, the warnings on these panels should clear.
